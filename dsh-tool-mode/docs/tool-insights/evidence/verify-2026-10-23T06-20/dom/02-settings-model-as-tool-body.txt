Install
Expose unavailable models

Register a tool even when its runtime is missing, so a model turn can discover why it cannot run.

Register skills

Publish one skill per registered tool, teaching when to use it.

Register the inspection tool

Expose the model_tools inspection surface to authorised native callers.

Allow in-process packages

Resolve model packages from this installation. Turn off to force every call through the CLI or the bridge.

Managed workers

Run extension entries in a managed child process with a scrubbed environment.

Repair attempts

Bounded title-repair budget per call (0-8). Out-of-range values are refused, never clamped.

Approved roots

Comma-separated absolute paths file-reading tools may reach. Empty approves nothing.

Allowlist override

Advanced: comma-separated model ids. Empty means every enabled model below; set only to pin an exact set.

Save

Per-model toggles write the exclude list; the allowlist override pins an exact set. Credentials, the bridge endpoint, the extension store and the headless MCP listener live in the profile cordis.patch.yml row (id "model-tools"), where the launcher and doctor read them.
