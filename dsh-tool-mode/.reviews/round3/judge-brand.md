**Verdict:** one authored system now — card anatomy, family tints and editorial tone hold. Three blockers keep it from ship.

## Remaining blockers

1. **The panels don't rhyme.** CODE MODE traces semantic_rank, decision_choose, structured_extract; MCP exposes the decision trio. CODE MODE also regressed: the return line prints twice and its meta lines disagree — "HOST-REPORTED" against "HOST-RECEIPT LOCAL". State one fact once, with the same three calls in both panels.
2. **Icon motifs still collide.** Three tiles are "geometry + arrow" (multimodal_embed, semantic_rank, dedupe_and_rank) and two are braces (structured_extract, extract_with_repair); the repair icon reads as clutter at tile size, and tools_plan is still typographic boxes. Give each a distinct figure.
3. **Micro-type and one flat figure.** Kickers and footer slugs remain ~5px at low contrast, and Laya's salmon bar on rust is roughly 2:1, so its only figure dissolves at a glance. Raise the small type to 9px; separate the bar by value.

Fixed since round 2: the badge now reads READY + MCP, card grounds harmonise, Tongue and Voz earn their marks.

Ship after the three.
