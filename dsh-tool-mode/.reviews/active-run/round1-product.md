# Active Run — round 1 review (product)

**Direction 7.5/10** — Concept 8 · Craft 8 · Clarity 6.5. "A call is a job" is the strongest frame this project has had; the card doesn't yet prove it.

**What works:** the H1/eyebrow pairing ("the call is the unit"), one bordered card spotlit on black, the orange→lime accent logic, and an honest run object (id, status, tools, model, trace).

**"A call is a job" without explanation?** The page says it; the card doesn't. Strip the H1 and this is a model-run status panel: no attempts, queue position, owner, duration, logs, result, or cancel/retry/handoff — though the subhead promises retry and hand-off. A job is a lifecycle; this is four rows.

## Five fixes

1. **Resolve "Running" + "TRACE 100ms".** A running job cannot have a completed trace, and the ghost panel behind also says 100ms. Use a live elapsed timer and "—" trace while running, or "Succeeded · 100ms" with "View run"; add the state ladder.
2. **Make the dome earn its area.** ~10 unlabeled rays under "three calls" contradicts the caption. Make it the trace — three branches, tool names at the tips, 44/39/61ms on the arcs — or cut it and give the evidence the space.
3. **Prove the job in the object.** Run name/intent as the title (not "Running the decision."), run id secondary, attempts "1 of 3", started/duration, owner, a result line, and cancel/retry/hand-off actions.
4. **Rebalance the left and ghost layer.** Left content stops at the stats (y≈640), leaving 450px dead while the card runs to 930; the dim dashboard is one cropped latency panel that reads as an accident. Show a legible dim queue/recent-runs layer or drop it; align stats and card footer on one baseline.
5. **De-duplicate the card.** The blue "laya · decision" badge duplicates MODEL → Laya; TOOLS 3 + "MCP · 3 EXPOSED" + the orange 3 EXPOSED stat say 3 three times; "ONE PROGRAM / THREE CALLS / ONE TRACE" is the smallest text at 6px. One row per fact, 10px floor, and integrate or remove the blue.
