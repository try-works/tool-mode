# Active Run V3 — brand review, round 3

**Concept 9 · Craft 8** (was 7) **· Clarity 8** (was 7).

The unit is right: intent title, run id, lifecycle, calls with durations, actions and a recent-runs rail make the card a job record on its own. "A run is a job." no longer needs the paragraph, and "EVERY RUN KEEPS" earns the left column.

## Three blockers

1. **Row four pairs the wrong things.** STATUS|DURATION, ATTEMPT|TOOLS, STARTED|RESULT read correctly; TRACE|OWNER doesn't — owner is identity, not lifecycle. Put OWNER beside the run id and keep row four for trace state.
2. **RESULT contradicts STATUS.** "Running" in green and "running" in white one column apart. If the run is live, RESULT reads "—" or "pending": one fact, one casing, one colour. Raise the 5px COPY ID chip or delete it.
3. **The dome is now an unlabelled glyph.** Shrinking it was right, but it must state something: caption it "2 of 3 complete" and align its baseline to the call table, or remove it.

Ship after these; no structural work remains.
