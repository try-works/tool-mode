# 19 / Active Run — Craft Review

**Concept 8 · Craft 7.5 · Clarity 6.5**

This is a strong direction: one bright run card over a dim console, with the call as the hero object. The headline, orange frame, status table and run ID establish “unit of work” quickly. It does not yet fully say “a call is a job” without the headline — the card reads as a run summary, not an inspectable job.

## Five fixes

1. **Make the dome the trace, or cut it.** It is a beautiful unlabeled object with ~14 ribs while the table says 3 tools, so it contradicts the count and carries no time. Draw three labelled radial spans (tool name + ms), one live node, and rings as phases; or replace it with a three-row waterfall. If decorative, drop it to 20% and give data the space.

2. **Add job affordances and lifecycle.** “Inspect, retry and hand off” exists only in body copy. Add attempt/started-at, Retry / Hand off / View trace actions, and a result or artifact row. Without controls this is a status poster, not a job.

3. **Fix the data grammar.** “TOOLS 3”, the page’s “3 EXPOSED” and the “MCP · 3 EXPOSED” chip read as three versions of one number. Label “tools in this run” vs “MCP-exposed tools”, move provenance beside trace, and remove the duplicate “laya · decision” chip or make it the family colour. The run ID should be 11px mono with copy — not 9px ghost text.

4. **One accent, larger microtype.** Orange + green + blue is one colour too many; the blue chip is foreign to an orange card and to Laya’s old family hue. Keep orange for brand/active, green for state, neutral elsewhere. Raise labels, chips and footer from 8–10px to 11–12px at 4.5:1; “READ THE DOCS” is nearly invisible.

5. **Rebalance left and commit the dim dashboard.** The left column dies after the stats — roughly 350px of empty black — and the card has matching dead bands. Anchor the stats to the card’s bottom or add a compact call → run → inspect rail; make the background console legible at 8–12% (latency, recent runs, tool list) so the card reads as the active layer rather than the only layer.
