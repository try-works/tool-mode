fix(client): one row action no longer disables the whole extension page

Installing one extension passed extBusy (extPending !== null) to EVERY row, so
all switches and action buttons greyed out until the install finished. The busy
flag is now scoped to the row whose action is in flight; every other row stays
operable and the host's own refusal (for example a lifecycle operation in
progress) is shown on that row instead of locking the page. Adds a bundle +
template assertion for the scoped busy state.

Bumps @try-works/dsh-tool-mode to 0.5.52; regenerates verification.
